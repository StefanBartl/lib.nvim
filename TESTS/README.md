# Tests

Headless spec suite for lib.nvim. Covers pure / buffer-level logic that is
testable without a UI.

## Run

From the repo root:

```sh
nvim --headless -u NONE -l TESTS/run.lua
```

or:

```sh
nvim --headless -u NONE -c "set rtp+=." -c "luafile TESTS/run.lua" -c "qa!"
```

The runner prints one line per spec and exits non-zero on the first failure
(`LIB_TESTS_OK` on success).

## Layout

The table below is in `run.lua`'s own load order. Entries carried over from
before this pass keep their original, more detailed wording; entries added or
reconciled in this pass are intentionally terser — a pointer to the module and
its major branches, not a full walkthrough. Several rows below existed in
`run.lua` long before they had a row here at all — this table had drifted
significantly out of sync with the actual spec list; that gap is closed now,
not carried forward.

## Adding a spec

Create `<name>_spec.lua` returning `function(H) … end` (use `H.eq` / `H.ok` /
`H.tmpfile` / `H.read_lines`) and add its filename to the `specs` list in
`run.lua`.

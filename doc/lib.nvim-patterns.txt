1. OVERVIEW                                       *lib.nvim-patterns-overview*

  A catalogue of the classic Gang of Four patterns and common modern ones.
  Each pattern is either a pointer to the lib.nvim module that already is the
  pattern, a small tested reference implementation, or a documented idea. The
  editor-independent ones live in lib.lua.patterns.<name>, the ones that need
  the editor in lib.nvim.patterns.<name>. Every module has a README.md next to
  its source with a section "When it helps / when it does not (Lua view)": use
  a pattern only when it simplifies the code, not for its own sake. The full
  table is docs/patterns.md.

==============================================================================
2. STAGES                                           *lib.nvim-patterns-stages*

  reuse   lib.nvim already has the pattern as a feature module (9).
  impl    small tested reference implementation (26).
  idea    rarely useful in Lua, kept as a documented reference (8).
